# Project Description
This is a cookbook website created using HTML, PHP and MySQL. Recipe information is stored in a database and is displayed on a webpage. Users will be able to use this application to search for recipes, view recipe information, and manage recipe data in the cookbook.

# How do I run it?
To run this project locally, you will need XAMPP or MAMP, depending on your operating system, with Apache and MySQL running.
Create a MySQL database for the project and import your schema.sql file.
Copy config.example.php and rename the copied file to config.php.
Enter the database credentials for your local MySQL installation; host, username, password, and database name.
Place the entire project folder inside the htdocs folder in your XAMPP or MAMP application folder.
Open a web browser and navigate to the project through localhost. (http://localhost/idm232-abc123/)
